## Tech stack

- Angular  - A TypeScript-based web framework for building dynamic, single-page applications
- Typescript - A typed superset of JavaScript that compiles to plain JavaScript
- Angular Material - a UI component library for Angular that follows Google's Material Design to create responsive and accessible web interfaces.
